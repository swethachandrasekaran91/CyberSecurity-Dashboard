# Cybersecurity Dashboard

Interactive Tableau dashboard analyzing global cyber attacks from 2015–2024.

## Tableau Dashboard
https://public.tableau.com/views/CyberAttackAnalysis2015-2024/AttackAnalysis

## Features
- Attack trends
- Country analysis
- Financial loss insights
- Industry-wise threats
- Interactive filters

## Tools Used
- Tableau Public
- Excel / CSV
- Data Visualization
